# CV description

**Electricity Auction Curve Forecasting — Python, Machine Learning, Time Series**  
Developed an X-Model-inspired research pipeline for day-ahead electricity forecasting using public OMIE supply and demand curves, including market-curve reconstruction, regularised and nonlinear class-volume models, and leakage-safe walk-forward evaluation against direct price benchmarks. Built the project as a reproducible Python package with data provenance, DST-aware processing, testing and explicit separation of market-clearing, curve-compression and forecasting error.

Use this wording only for the implemented methodology. Do not add claims about empirical model superiority unless a successful real-data run supports them.
