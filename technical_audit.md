# Independent technical audit

Date: 2026-11-14

This audit distinguishes implemented/tested software from empirically verified market results. Because official raw OMIE files cannot be materialised in the current runtime, no downstream empirical stage is labelled VERIFIED merely because its code exists.

|---|---|---|

| 17. Is the code reproducible from README instructions? | PARTIALLY VERIFIED | Editable installation and test execution succeed in this runtime; data download requires normal external network access. |
| 18. Are dependencies and versions documented? | VERIFIED | `pyproject.toml` defines Python and dependency ranges. |
| 19. Are limitations stated transparently? | VERIFIED | README, methodology, data sources, execution status and results report state the current blocker and modelling limits. |
